# 0009 · 移除记忆条目的依据类型（kind）

- 状态：**Accepted**（2026-11-18 用户决定）。取代 ADR-0006 中"条目依据类型（kind）"一节，以及阶段 2 中按依据强弱校验的部分；ADR-0006 的其他内容不变。
- 日期：2026-11-18

## 背景

Schema v1 给每条系统记忆标注依据类型 `kind:observed | stated | inferred | confirmed | unknown`，由整理时引用的依据推导，并在记忆浏览界面与 MCP 输出中展示。实际情况是：

- 绝大多数条目来自屏幕推断，标签几乎都是"推断"，对用户的信息量很低；
- `confirmed` 没有任何产生途径：目前没有用户确认记忆的入口，也没有 Agent 写入记忆的机制；
- 依据强弱规则（取最弱、不以弱覆盖强、F 只能证明应用使用）让整理逻辑和提示词明显变复杂，却无法真正回答"这条记忆从哪来、谁确认过"。

来源与确认应当和今后的 Agent 写入机制一起统一设计，而不是在当前只有自动整理的阶段先固化一套分类。

## 决策

- 移除 `MemoryEntryKind` 与未使用的 `MemoryEntry`，`MemoryItem` 不再有 `kind`。
- 新写入的条目只记录来源日期 `src:` 与结构化字段（如财务的 `amount:` / `cur:` / `txn:`）。
- 记忆浏览界面不再显示依据标签。`MemoryAPI` 与 MCP 的 `search_memory` / `get_memory` 输出去掉 `kind` 字段。
- **兼容旧数据**：读取时忽略旧条目上的 `kind:`，条目文字、来源日期和其他字段照常读入，不丢条目。文件本身不做批量迁移，旧标签留在原处，直到整理下次改写该文件的系统区块时才不再写出；改写前照常存快照。
- **保留溯源**：
  - 整理仍必须引用依据编号，没有可采纳依据的条目一律拒绝；
  - 来源日期由引用的依据推导，从日期可以跳到当天的时间线、摘要与 daily 文件；
  - 时间线的 `seg:` / `conf:` / `src:` 与抽取层的事实 / 推断区分不变；
  - 引用采集元数据（F）时，条目必须提到其中的应用，否则不采纳该引用。
- **保留 Health / Finance 的保护**，改为不依赖 kind 的引用检查：只接受全部引用用户本人写下的内容（S / U）、且条目文字出自原话（二元组覆盖率 ≥ 0.4）的条目。"医学诊断"同样受此约束，诊断措辞仍不得出现在其他小节。这比原规则略严：原规则也接受只陈述应用使用的观察依据，这类依据本来就不构成健康或财务数据。
- 统一的来源与确认机制（谁写的、谁确认过、可信度如何裁决冲突）等 Agent 写入机制实现后再设计，届时另立 ADR。

## 备选方案

- **保留 kind，只隐藏界面标签**：仍要维护推导与强弱规则，复杂度不降，而且 MCP 与文件里仍然暴露一套即将被替换的分类，因此未采用。
- **把旧 `kind:` 当作普通结构化字段原样保留**：不丢任何字节，但它会出现在 MCP 的 `attributes` 和整理提示词里，等于换个名字继续存在，因此未采用。
- **启动时批量去掉所有旧标签**：会无故改写用户文件，而且没有必要，因此未采用。

## 取舍与风险

- **失去"不以弱覆盖强"的代码保护**：整理现在可以仅凭屏幕推断改写或撤下原本出自用户陈述的条目。目前只靠提示词约束（"不要仅凭屏幕推断改写或撤下已有条目"），被改写、撤下的旧内容留在变更记录与快照中，可以找回。这是本次决定最主要的代价，应在设计统一的确认机制时优先补上。
- 同文条目不再按依据分开保留，合并后只剩一条，来源取并集。
- 评测不再计算依据类型正确率；场景文件中旧的 `kind` 期望字段解码时忽略。held-out 场景文件按规则不修改。

## 影响

- 代码：`AmaiCore`（删除 `MemoryEntry.swift`）、`MemoryItems`、`EvidenceLedger`、`CategoryUpdater` / `CategoryPolicy`、整理提示词、`Consolidator`（General 选取改为按来源日期从新到旧）、`MemoryAPI`、`AmaiMCPServer`、`MemoryBrowserView`、`SchemaMigration`、`MemoryEvaluation`。
- 文档：`docs/memory.md`、`docs/architecture.md`、`docs/mcp.md`、README。
- 示例数据（`samples/memory-preview*`）去掉 `kind:`。README 中已有的记忆浏览截图仍带旧标签，需要重新截取。
