# 架构决策记录（ADR）

每个重要技术 / 架构决策一个文件，编号递增，文件名 `NNNN-<slug>.md`。

状态：`Proposed`（提案，待用户确认）→ `Accepted` / `Rejected` → `Superseded by NNNN`。

模板：

```markdown
# NNNN · 标题

- 状态：Proposed | Accepted | Rejected | Superseded by NNNN
- 日期：YYYY-MM-DD

## 背景
## 决策
## 备选方案
## 取舍与风险
## 影响
```
