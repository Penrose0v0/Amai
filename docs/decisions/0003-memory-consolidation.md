# 0003 · 记忆整理（M4）：日终摘要、work 专题与 summary

- 状态：**Accepted**（2026-10-20 用户确认方向：接近 OpenClaw 的 Markdown 记忆机制，由 LLM 判断保存、更新与舍弃，不做过度工程）
- 日期：2026-10-20

## 背景

M3 之后，活动片段自动写进 `daily/` 的时间线。M4 让记忆沉淀下来，只保留三个功能：

1. 每日整理 daily，生成日终摘要。
2. 根据 daily 自动创建、更新 `work/` 下的专题记忆。
3. 定期整理并更新 `summary.md`，沉淀长期重要信息。

## 决策

### 机制（参考 OpenClaw 的 Dreaming / MEMORY.md）

- **LLM 决定内容**：每次整理时，模型拿到"现有的系统记忆 + 新材料"，返回更新后的完整条目列表。保留、合并、改写、舍弃哪些条目，都由模型判断。不设晋升门槛，不做审批或确认流程。
- **代码负责安全**：
  - **只写系统区块**：沿用 M3 的 HTML 注释区块，每个文件里系统只改写自己的区块，用户手写内容永不覆盖。用户手写的部分作为上下文交给模型，避免重复或矛盾。
  - **来源追踪**：每条记忆以 `<!-- src:YYYY-MM-DD,… -->` 标注来源日期；模型漏写时由代码补上当天日期。
  - **快照**：任何整理改写文件前，旧版本存入 `~/Library/Application Support/Amai/snapshots/`，保留最近 100 份，并在同目录的 `changes.jsonl` 记一行改动。
  - **防重复写入**：同一天只整理一次（状态记录在 `index/consolidation.json`）；条目按规范化文本去重；改写前重读文件；内容未变不写。
  - **防大量丢失**（OpenClaw 的 `maxPriorEntryLossFraction`）：一次改写使已有条目减少一半以上时拒绝写入，记录错误，旧内容保持不变。
- **模型可替换**：整理通过 `MemoryLanguageModel` 接口调用模型，不绑定具体模型。M4 暂时接到本地默认模型，云端 API 大模型支持见 ADR-0004（规划中）。整理的输入只有记忆文本与片段统计，不含截图和 OCR 原文。

### 1. 日终摘要

- **触发**：本地时间凌晨 4 点后整理前一天；应用关闭过的话补整理，每轮最多 3 天；也可以从菜单手动整理今天。
- **输入**：当天 daily 全文（时间线 + 用户手写），以及代码算出的活跃时长与分类时长。
- **输出**：daily 中"## 摘要"下的 `amai:digest` 区块，放在时间线上方。内容是一行统计、2 到 3 句总览和 3 到 5 条要点。

### 2. work/ 专题

- 与日终摘要在同一次整理中进行。
- **输入**：当天 daily（含刚生成的摘要），以及 `work/` 下已有文件的标题和系统条目。
- **输出**：模型决定更新哪些已有文件、是否新建文件（每天最多新建 3 个），对每个文件返回完整条目列表。
- 文件路径必须位于 `work/` 下并以 `.md` 结尾，否则丢弃。条目写在每个文件"## 记录"下的 `amai:memory` 区块，每个文件最多 40 条。

### 3. summary.md

- **触发**：每 7 天一次；首次运行在有了至少 2 天的日终摘要之后。也可以从菜单手动触发。
- **输入**：summary 当前全文（用户手写部分作为已知事实），最近 7 天的日终摘要，`work/` 各专题的标题与主要条目。
- **输出**：summary 中 `amai:memory` 区块，按固定小节分组：基本背景、工作与研究、习惯与偏好、长期目标、重要关系、其他。最多 40 条。

### 保留

M4 不做自动遗忘。raw 截图保持 72 小时，抽取结果与记忆文件保持不变。

## 已放弃的方案

此前的提案（"移出区块即确认"、14 天 3 次晋升门槛、summary 只提案待确认、指纹黑名单）机制过多，与"由 LLM 维护系统记忆"的方向不符，于 2026-10-20 放弃。准确性主要靠来源追踪与快照兜底：用户可以随时查看来源、回滚，或直接改写。

## 影响

- `AmaiMemory` 新增 `Consolidator`、通用系统区块 `SystemBlock`、条目格式 `MemoryItems`、`SnapshotStore`，以及模型接口 `MemoryLanguageModel`。App 用抽取层的 `ModelProvider` 适配这个接口，记忆层不依赖抽取层。
- 菜单新增"整理今天"和"更新长期记忆"两个入口。
